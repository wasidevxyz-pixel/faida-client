# Payroll Slip Assets Folder

Place your custom images here. The payroll slip will automatically use them.

## Required Files:

| File Name          | Purpose                        | Recommended Size  |
|--------------------|-------------------------------|-------------------|
| `logo.png`         | Company logo (center of slip) | 150x150 px (square) |
| `stamp-bank.png`   | "Bank Paid" stamp image       | 200x200 px        |
| `stamp-cash.png`   | "Cash Paid" stamp image       | 200x200 px        |
| `stamp-advance.png`| "Advance Paid" stamp image    | 200x200 px        |

## Notes:
- Use PNG format with transparent background for best results
- If a file is missing, the slip will show a default CSS text stamp
- Logo appears in the CENTER column of the salary slip
- Stamps appear rotated (-15 degrees) with 35% opacity over the center area
- Supported formats: PNG, JPG, JPEG, GIF, SVG
